# Zone-first patterns

Read by Opus on 2026-10-06 from 17 builder plans the user shared. The images stay local in the gitignored `knowledge/reference/ideal/` folder (`zf-00` … `zf-16`). Only the derived numbers below are committed.

All numbers are provisional. Dimensions marked "est." were estimated from room sizes because the plan shows no overall size.

## The user's idea (2026-10-06)

1. Place the essential zones first: Family Core (kitchen, dining and living), the Master block (bedroom, ensuite and WIR as one block), the other bedrooms, the bathroom/WC block, the laundry and the garage.
2. **Maximise the buildable envelope.** Every gap inside it becomes **flex**. That includes the alfresco, a courtyard, a porch and any other open space inside the envelope.
3. A flex space can later become a room (theatre, office, activity) or circulation (a hallway or walk-through).
4. Walls come later. An architect refines the result.

This idea overrides three earlier decisions: the D21 amendment (smallest footprint), D64 (less Flex ranks first) and D44 (flex is only leftover).

### Rules this changes or adds (provisional; the user has not adopted them as decisions)

- **R2 (revised): the spine is short.** It runs from the front door only as far as it needs to reach the first rooms. The rest of the circulation is the Core itself or narrow Flex halls.
- **R3 (revised): the Core can sit in the middle**, not only at the rear (zf-03, zf-04, zf-05, zf-07, zf-08). Once the alfresco counts as Flex inside the envelope, the rear wall is often taken by a bedroom row and the alfresco Flex.
- **R4 (revised): bedrooms can form a rear row** along the rear wall (zf-04, zf-05, zf-07, zf-08), not only a side stack. Rooms in a column fill the column width, rather than keeping their preferred width and leaving a Flex strip.
- **R9 (new): "flex-wall" halls.** These are short, narrow Flex halls (about one hallway wide) that branch off the Core or the spine to reach a wet room, laundry or rear bedroom. The user likes them: they are what makes a generated plan look complex and real.
- **R10 (new): the Master block can split.** It is usually one block, but the generator should also be able to separate the parts (for example `master + wir` with the ensuite apart, as in zf-08), so the Flex between them can become a room or a walk-through.
- **R11 (new): the Core can be L-shaped or split** into named parts (`famcore *d`, `famcore *k+l`, `famcore *k+living`). The generator should be able to try both the split version and a single block.
- **R12 (new): Flex can be walk-through**, like the Core, so it can carry circulation as well as become a room.
- **Scope (2026-10-07): front entrances only.** Skip layouts whose entry is at the side (zf-02, and any side-entry candidate) for now.

Table correction: zf-03's Core is **middle, L-shaped**, not "band". zf-12 still needs checking.

### Extensions (user 2026-10-07, provisional)

- **R13: extensions.** Some leftover space belongs to one zone. A piece becomes an extension when it lies in line with that zone, between it and the outside wall. The zone keeps its preset size, and the extension is a separate, labelled piece attached to it (for example `Core · extension`).
- **Who decides what it becomes:** the architect or the later wall-builder stage. Either it merges into the zone (no wall), or it becomes its own space (utility, alfresco, storage and so on).
- **How it differs from ordinary Flex:** Flex is shared between several zones, and an extension belongs to one.
- **Origin:** the user's drawings stretch rooms to the envelope edge (for example zf-00's full-width Core) to use space that would otherwise be wasted. Extensions keep that intent without breaking the room-size presets.
- **Labels:** wording beyond the generic "· extension" is a later copy decision.

### Sizing decisions (user 2026-10-07, provisional)

- **Big lots: grow rooms first, then Flex.** When the lot is much bigger than the room list needs, rooms and the Core grow toward their CATALOG maximum sizes first. Only what is still left becomes Flex, for extra rooms such as a theatre or study. This applies only when the leftover is beyond the profile's Flex ceiling. On normal lots, the zf-07 rule still holds: rooms stay near their preferred size, with room-sized Flex beside them.
- **Family Core cap stays at 58.5 m².** A Core that needs to be bigger (the user's zf-08 is about 71 m²) gets a `Core · extension`, so the architect sees it was oversized. zf-08's blind test stays a todo for this reason.
